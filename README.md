# 寶寶手冊 · 兒童健康紀錄（PWA）

依國健署兒童健康手冊時程做的手機 App。純前端、無後端，資料只存在使用者手機的 localStorage。

## 部署

把四個檔案放進 GitHub Pages repo 的根目錄：

```
index.html      主程式（單檔，含所有 CSS/JS）
manifest.json   PWA 設定
sw.js           離線快取
icon-192.png / icon-512.png / icon-maskable.png
```

必須用 HTTPS（GitHub Pages 本來就是），Service Worker 才會生效。

安裝方式：
- iPhone：Safari 開啟 → 分享 → 加入主畫面
- Android：Chrome 開啟 → 選單 → 安裝應用程式

改過 `index.html` 之後，記得把 `sw.js` 裡的 `const V = 'bbh-v1'` 版本號 +1，使用者下次開啟才會拿到新版。

## 加上生長曲線百分位

`index.html` 最上方有一個 `REF` 物件，預設是空的，所以圖上只會畫寶寶自己的曲線。
把 LMS 參考表填進去，P3/P15/P50/P85/P97 參考線和百分位計算會自動出現：

```js
const REF = {
  ht:{ M:[{a:0,L:1,M:49.88,S:0.0379}, {a:6,L:...}, ...], F:[...] },
  wt:{ M:[...], F:[...] },
  hc:{ M:[...], F:[...] }
};
```

- `a` 是月齡，不必逐月填，關鍵月齡即可，中間會線性內插
- `M` 男、`F` 女
- 可以直接沿用你生長曲線 App 裡那份台灣參考表，轉成這個格式即可

## 內容依據

全部對照《兒童健康手冊》中文版（出版年月 115 年 6 月）核對過：

- 兒童預防保健 9 次（手冊 p.6–7）：出生 2 週–2 個月、2–4 個月、4–6 個月、6 個月–1 歲、1–1.5 歲、1.5–2 歲、2–3 歲、3–5 歲、5–未滿 7 歲；出生 6 天內新生兒檢查另計
- 兒童發展篩檢 6 次（就醫憑證綠卡）：6–10 個月、10 個月–1.5 歲、1.5–2 歲、2–3 歲、3–5 歲、5–未滿 7 歲
- 常規與自費疫苗：手冊「預防接種時程及紀錄表」及續 1、續 2
- 牙齒塗氟：未滿 6 歲每半年 1 次（手冊自第 4 次健檢起提醒）
- 各次健檢的發展診察項目、各階段里程碑：依手冊發展診察欄位改寫

百分位曲線採手冊同一組 P97/85/50/15/3。

App 只做時程計算與紀錄，不含手冊衛教內文。
時程資料集中在 `CHECKUPS`、`SCREENS`、`VAX`、`FLU` 四個陣列，政策調整時改這四處就好（流感疫苗分齡欄位在 `FLU_BANDS`）。
